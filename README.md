# Tech-Study

IT技術の学習・検証用プロジェクトリポジトリです。
Webアプリケーション開発からインフラのコード化 (IaC)、資格試験の学習まで、多目的なプロジェクトを管理します。

## ディレクトリ構成

- `01_ai/`: AI技術関連
  - RAG構築、LLMのAPI活用（OpenAI、Gemini等）や各種AI技術の検証
- `02_apps/`: アプリケーション関連
  - `frontend/`: Vue, Reactなどのフロントエンド検証用
  - `backend/`: Laravel, Rails, FastAPIなどのバックエンド検証用
- `03_infra/`: インフラ・サーバ関連
  - `aws/`: AWS CLIのスクリプトや構成管理など
  - `terraform/`: Terraformの定義ファイル
  - `ansible/`: AnsibleのPlaybookやInventoryなど
- `04_certs/`: 資格取得関連
  - `ap/`: 応用情報技術者試験のメモや関連スクリプト
